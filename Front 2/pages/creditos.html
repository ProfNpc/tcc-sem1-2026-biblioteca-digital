👨‍💻 Equipe de Desenvolvimento

Desenvolvimento Frontend

Interface, UX/UI, JavaScript, i18n e integração com a API REST. HTML5, CSS3 com design responsivo e sistema de carrossel interativo.

Desenvolvimento Backend

API REST com Java 17 e Spring Boot. Modelagem de banco de dados MySQL, autenticação de usuários e regras de negócio para o sistema de reservas.

Orientação Técnica — ITB

Professores e coordenadores do Instituto Tecnológico de Barueri que orientaram e acompanharam o desenvolvimento do projeto de TCC.

🛠️ Recursos e Ferramentas

Unsplash

Fotografias de alta qualidade utilizadas nas capas de livros e imagens da interface. Disponíveis gratuitamente em unsplash.com sob licença Unsplash License.

Google Fonts — Inter

Tipografia Inter utilizada em toda a plataforma. Disponível em fonts.google.com sob licença SIL Open Font License.

FlagCDN

Ícones de bandeiras para o seletor de idioma (PT/EN). Disponíveis em flagcdn.com.

Google Maps Embed API

Mapas interativos para exibição da localização dos polos ITB no modal de geolocalização.

Princípios de código limpo aplicados na organização e manutenibilidade do código-fonte do projeto.
